# WordTrace 1.0.1 验证记录

验证日期：2026-09-22。

设备识别流程和界面截图来自 1.0.0 候选包；1.0.1 补上忙碌时保留待处理帧的保护及 CI 配置修正，并重新运行本地单元测试、debug/release lint、发布构建和签名验证。

## 自动检查

- JDK 21、Gradle 8.9、Android Gradle Plugin 8.7.3、SDK / Build Tools 35。
- `testDebugUnitTest`：8 项通过，覆盖连续停留、消失后重现、短暂 OCR 漏字、标点与忽略词、暂停恢复、频次排序、慢帧与导出内容。
- `lintDebug`、`lintRelease`：通过，无问题报告。
- Android 15 MuMu 设备测试：2 项通过，覆盖内置模型识别 `apple banana` 和检查点 / CSV / TXT 读写。
- `assembleRelease`：通过；APK v2 签名验证通过，RSA 3072。
- 最终合并清单：没有 INTERNET、ACCESS_NETWORK_STATE、麦克风、无障碍或存储读取权限。

## 实际录制流程

在 Android 15 MuMu 中，通过真实 MediaProjection 系统授权共享测试页面，观察以下过程：

1. 显示 `apple`，持续停留，词表计为 1。
2. 切到 `banana` 并停留超过 2 秒，得到各 1 次。
3. 切回 `apple`，得到 `apple: 2, banana: 1`。
4. 暂停期间切到 `cherry`，词表不变。
5. 回到 `apple` 并继续，次数不因暂停而增加。
6. 点击结束，生成 CSV、TXT；两种文件均包含 `apple 2` 与 `banana 1`。

截图中的词表为这次人工构造的测试记录，不是真实用户学习数据。调试用的测试页面仅存在于 debug 变体，不打入正式 APK。

## 界面

同一 Android 15 模拟器分别采用手机 720×1280 / 240dpi 和平板 1600×1200 / 160dpi 配置检查，包含深色模式、1.3 字体缩放、悬浮窗、词表及导出选项。平板分隔线测量问题已修复。模拟器显示设置在检查后恢复。

## 未验证范围

- 未连接用户实际手机、平板；未在用户所安装的不背单词版本上实测。
- Android 8–14 的真机 / 厂商后台策略、16KB 页大小设备尚未实测。
- 系统文件选择器「另存为」及各第三方分享接收器需在实际设备确认；已验证应用生成的文件内容及导出选项界面。
- 大字筛选和区域裁剪为通用启发式，识别准确率不作保证；快速翻页和受保护画面可能漏词。

本记录说明实际验证边界，不等同于所有安卓设备兼容认证。
