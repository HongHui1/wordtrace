## 1.3 速度测量

相同模拟器、不背单词版本与 1280×720 横屏词卡，从点击下一词前开始计时，通过每约 100ms（另含 ADB 耗时）读取会话检查点，看到该词写入后停止。包含翻页动画、OCR、两次确认、文件写入及观察延迟，不是单独模型耗时。

| 目标词 | 1.2.0 | 1.3.0 改进后的实测 |
| --- | ---: | ---: |
| unite | 2126ms | 1488ms |
| unity | 1768ms | 1509ms |

这是两张相同词卡、相同向前刷词方向的单次样本，不能代表所有设备或页面的平均速度。新版另外 7 张词卡的该次测量为 1341–2061ms。之后的采样调度还去掉了慢 OCR 错过整次定时周期的空等：调试日志确认 518ms 的识别结束后立即继续，而不是等到下一个一秒周期；最终 union 的完整写入测量为 1513ms。

改善包括后台像素复制、裁剪、解析和词表加载，按需缓存词表，最近静止画面确认，以及大字模式限制 OCR 分辨率。没有量化验证真机帧率、续航或长时间学习负载，不宣称在 vivo 上达到相同耗时。
