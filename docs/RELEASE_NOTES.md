# WordTrace 1.3.0 · 实际不背单词验证与操作优化

- 用 MuMu 中的不背单词 5.11.6 实测学习卡片，收紧大字模式，排除首页菜单、词书列表与小字例句；大字不完整时不会转而记录例句。
- 先组合不等高字母，再进行字号筛选，减少完整词被拆成片段的情况。
- 每半秒尝试取帧，慢识别完成后继续调度；后台完成图像处理与词表加载，静止画面也能确认目标词。
- 36dp 小球自动贴边、记住位置、旋转仍贴边。菜单缩为两行，右侧展开保持小球原位，操作后收起。
- 应用说明只提示一次，系统共享授权每次保留；授权完成后直接回到学习页面。
- 美化绿色首页与词表，增加单词预览、最近识别反馈和可清除的搜索，适配深色 / 放大字体 / 平板。

下载安装 `wordtrace-1.3.0.apk`，可覆盖此前正式版，保留旧词表。MuMu 中已安装对应测试版本；手机使用本次正式签名 APK。TXT 每行一个唯一单词，不统计频次，仍需在开始前结束系统录屏。

18 项单元测试、5 项设备测试、debug / release lint、构建与签名验证通过。实际截图覆盖 8 张词卡及首页 / 列表反例，真实采集另验证竖屏词卡、暂停 / 继续、旋转和系统文件另存。两张相同横屏词卡从点击下一词到写入文件，由旧版约 1.8–2.1 秒降至约 1.5 秒；这是单次 MuMu 小样本，不代表 vivo 真机表现。详细范围见 [TESTING.md](TESTING.md)。

## WordTrace 1.2.0 · 专注记录单词

这一版只把「识别完整单词并保存成文本」作为重点。

- 默认只识别大字目标词，避开例句与音标。
- 按字框位置重组拆开的字母，内置离线词表校验，并经过连续两帧确认后保存。缺失字母不补猜。
- 不再统计和显示频次，同一单词只保留一次。TXT 每行一个词，可保存文件、分享或复制。
- 精简首页，保留打开悬浮球、识别设置和我的词表；延续绿色日间 / 深色主题。
- 小悬浮球保留，点击展开控制，拖动移动，操作后收起。
- 移除录屏兼容模式和无障碍服务，统一使用系统屏幕共享；请先结束系统录屏。

下载安装 `wordtrace-1.2.0.apk`，可覆盖旧正式版，不必卸载；历史记录仍保留。首次按提示允许悬浮窗和系统屏幕共享，无需开启辅助服务。默认记录大字目标词，让单词稳定停留约两秒。

已通过 16 项单元测试、3 项 Android 12 模拟器设备测试、debug/release lint 和签名验证。实际模拟器流程把加大字距的 apple 保存为完整单词，跳过 appl，最终 TXT 为 apple、banana 两行，并通过系统文件选择器成功另存。

未在 vivo X100s 的真实不背单词页面上验证。词表未收录的词、单字母词、快速翻页等仍可能漏记；测试环境的一次初始化异常及详细范围见 docs/TESTING.md。

全部识别离线进行，不保存截图。代码 MIT，ML Kit 和 CMUdict 等依赖遵循各自条款。
