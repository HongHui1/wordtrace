# WordTrace 1.0.1

中文安卓悬浮窗单词记录工具。

本次收尾修正：在识别较慢的设备上保留最新待处理画面，避免忙碌时提前丢弃；GitHub Actions 改为安装当前有效的 Android SDK 包。

- 悬浮窗开始 / 暂停 / 继续 / 结束。
- 本地离线英文 OCR，自动统计出现轮次。
- 全屏 / 高度区域、大字优先、忽略词。
- 历史搜索，CSV / TXT 自动生成、分享及另存。
- 检查点恢复、深色模式和手机 / 平板布局。
- MIT 开源代码及 GitHub Actions 自动构建。

安装要求：Android 8.0 及以上。下载 `wordtrace-1.0.1.apk` 后直接安装，首次使用按提示允许悬浮窗与屏幕共享。

在不背单词中，默认会识别例句等全部可见英文；只想记目标词时可开启大字优先并调整识别区域。OCR 可能漏字、误字；相同词持续显示只记一次，消失约 2 秒后再次出现才增加。具体不背单词版本的兼容性仍需真机验证。

已通过 8 项单元测试、2 项 Android 15 模拟器设备测试、debug/release lint 和签名验证，实际测试录制结果为 `apple: 2, banana: 1`。详见 `docs/TESTING.md`。

词表默认保存在应用内，卸载前请另存。项目代码 MIT；Google ML Kit 模型及依赖遵循各自条款。
