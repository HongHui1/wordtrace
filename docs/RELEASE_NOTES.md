# WordTrace 1.1.0

修复启动记录可能打断系统录屏的问题，并把常驻悬浮窗缩成小球。

- Android 11+ 默认使用「录屏兼容模式」：由用户开启截图辅助服务，不申请 MediaProjection，不接管现有录屏会话。
- 辅助服务只申请截图能力，不读取控件树、不操作屏幕；只有主动开始记录后才截图。无法使用时不会自动切换到旧模式。
- 36dp 可拖动小球，轻触展开开始 / 暂停 / 继续 / 结束并保存；操作后自动收起，闲置八秒收起。
- 保留旧屏幕共享模式，启动前明确提醒可能中断录屏。
- 避免启动时把授权提示中的文字计入词表。更新中文使用说明及隐私说明。

## 安装

下载 wordtrace-1.1.0.apk，可直接覆盖此前正式版，无需卸载。Android 8+ 可安装，录屏兼容模式要求 Android 11+。vivo X100s 请保持默认兼容模式，首次按提示在系统无障碍 / 辅助功能中开启「WordTrace 录屏兼容识别」，返回不背单词后再次点小球开始。若系统提示受限设置，请按系统提示在应用信息中允许后再开启。

## 验证范围

8 项单元测试、2 项 Android 15 模拟器设备测试、debug/release lint 和签名验证通过。模拟器中，兼容识别的开始、暂停、继续和结束没有停止一个已经运行的真实 MediaProjection 测试会话；词表及导出复测为 apple 2、banana 1。未在 vivo X100s / OriginOS 自带录屏和用户实际不背单词版本上实测，详见 docs/TESTING.md。

识别离线进行，无联网权限，不保存截图。词表默认在应用私有目录，卸载前请另存。OCR 可能漏词或误认；出现次数是观察到的出现轮次。代码 MIT，ML Kit 等依赖遵循各自条款。
